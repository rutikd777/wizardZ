# WizardZ

WizardZ is a modern digital marketing agency landing page built with HTML, CSS, and JavaScript. It features smooth GSAP animations, a custom cursor, and a responsive design showcasing services, case studies, and partner brands.

## Features

- Animated navigation and hero section
- Service cards with scroll-triggered animations
- Case study highlights
- Custom animated cursor
- Responsive layout
- Uses [GSAP](https://greensock.com/gsap/) for animations

## Getting Started

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/wizardz.git
    ```
2. Open `index.html` in your browser.

## Dependencies

- [GSAP](https://cdnjs.com/libraries/gsap) (loaded via CDN)
- [Remix Icon](https://remixicon.com/) (loaded via CDN)
- [Google Fonts: Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)

## Customization

- Replace images in the `images/` folder to match your brand.
- Edit text content in `index.html` for your agency’s details.
- Tweak styles in `style.css` for colors and layout.
